# DKAB Etkileşimli Ders Sunumu

Türkiye Yüzyılı Maarif Modeli'ne uygun, 5. ve 6. sınıf Din Kültürü ve Ahlak Bilgisi dersi için tek dosyalık etkileşimli sunum uygulaması (401 slayt).

- **`DKAB_Sunum_v2.html`** — güncel sürüm: modern tasarım, konular çekmecesi, geri sayım, rastgele öğrenci seçici, tıklanabilir sorular, lazer/spot, klavye kısayolları.
- **`DKAB_Sunum_Final_82.html`** — orijinal sürüm (yedek).
- **`v2-kaynak/`** — v2'yi üreten tema, arayüz parçaları ve `build.py`.

Kullanım: HTML dosyasını tarayıcıda açın. Kısayollar için `?` tuşuna basın.

Yeniden üretmek için:

```bash
python3 v2-kaynak/build.py
```
